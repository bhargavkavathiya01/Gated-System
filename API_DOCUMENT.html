Nandi — New API Reference

Base URL: http://nandi.runasp.net/api  |  Auth: Authorization: Bearer <token> required on all endpoints  |  June 2026

1. Builder — Flat Owner

POST/api/builder/createflatowner form-data

Submit a flat owner creation request with Aadhar card and electricity bill documents. Requires admin approval before activation. Changed from JSON to form-data to support file uploads.

FieldTypeRequiredDescription
PropertyIdText✅Property ID
BuildingIdText✅Building ID
FlatNoText✅Flat number e.g. A-101
UserIdText✅Existing user's ID
RoleIdText✅Flat owner role ID
GuestTypeTextNoGuest type (optional)
AadharCardFileNoAadhar card image/pdf
ElectricityBillFileNoElectricity bill image/pdf
curl -X POST "http://localhost:5000/api/builder/createflatowner" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "PropertyId=1" \
  -F "BuildingId=2" \
  -F "FlatNo=A-101" \
  -F "UserId=5" \
  -F "RoleId=3" \
  -F "AadharCard=@/path/to/aadhar.jpg" \
  -F "ElectricityBill=@/path/to/bill.jpg"

2. Users

GET/api/user/getallusers

List all registered users with basic details — name, email, phone, role. Used for selecting SOS contacts.

curl -X GET "http://localhost:5000/api/user/getallusers" \
  -H "Authorization: Bearer YOUR_TOKEN"

2. Secretary — Society Images

POST/api/secretory/uploadsocietyimages form-data

Secretary uploads one or more society images for a property. Images are stored in AWS S3.

FieldTypeRequiredDescription
PropertyIdText✅Property ID
ImageTitleTextNoCaption for the images
ImagesFile✅Repeat field for multiple files
curl -X POST "http://localhost:5000/api/secretory/uploadsocietyimages" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "PropertyId=1" \
  -F "ImageTitle=Society Gate" \
  -F "Images=@/path/to/image1.jpg" \
  -F "Images=@/path/to/image2.jpg"

GET/api/secretory/getsocietyimages

Get all images uploaded for a property. Visible to all society members.

Query ParamRequiredDescription
propertyId✅Property ID
curl -X GET "http://localhost:5000/api/secretory/getsocietyimages?propertyId=1" \
  -H "Authorization: Bearer YOUR_TOKEN"

3. SOS — Emergency Contacts

All SOS endpoints read the logged-in user's ID from the JWT token automatically. No need to pass userId in the request body.

POST/api/user/addSOScontact

Add a user as an SOS emergency contact with an optional relation label (e.g. Father, Friend, Neighbor).

FieldRequiredDescription
contactUserId✅User ID to add as SOS contact
relationNoRelation label e.g. Father, Friend
curl -X POST "http://localhost:5000/api/user/addSOScontact" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "contactUserId": 5, "relation": "Father" }'

GET/api/user/getsoscontacts

Get all saved SOS contacts of the logged-in user with name, phone, email and relation.

curl -X GET "http://localhost:5000/api/user/getsoscontacts" \
  -H "Authorization: Bearer YOUR_TOKEN"

PUT/api/user/updateSOScontact/{id}

Update the relation label of an existing SOS contact. Use the id returned from getsoscontacts.

FieldRequiredDescription
relation✅New relation label e.g. Brother
curl -X PUT "http://localhost:5000/api/user/updateSOScontact/3" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "relation": "Brother" }'

DELETE/api/user/removeSOScontact/{id}

Remove a user from SOS contacts. Use the id returned from getsoscontacts.

curl -X DELETE "http://localhost:5000/api/user/removeSOScontact/3" \
  -H "Authorization: Bearer YOUR_TOKEN"

POST/api/user/triggersos

🚨 Instantly sends an emergency push notification to all saved SOS contacts of the logged-in user.

Push received by contacts — Title: 🚨 SOS Alert  |  Body: A contact needs your help urgently!
curl -X POST "http://localhost:5000/api/user/triggersos" \
  -H "Authorization: Bearer YOUR_TOKEN"
